# 邮政编码表

整理日期：2026-11-14

## 1. 全球各国家和地区邮政编码表（根目录）

| 文件 | 说明 |
|---|---|
| `全球各国邮政编码表.xlsx` | 工作表：说明 / 全部 / 亚洲 / 欧洲 / 非洲 / 北美洲 / 南美洲 / 大洋洲 / 南极洲 |
| `全球各国邮政编码表.csv` | 扁平表（UTF-8 带 BOM） |
| `全球各国邮政编码表.md` | 按区域分组的可读版本 |
| `全球各国邮政编码表.txt` | 纯文本版本（Windows 换行，记事本可直接打开），每行一个国家，字段以“ | ”分隔 |
| `邮政编码表合集.txt` | 合并版纯文本：第一部分为全球各国表，第二部分为中国大陆省市县表 |

- 覆盖 ISO 3166-1 全部 250 个国家和地区：中文名、英文名、ISO 代码、所属区域、有无邮编、邮编格式、示例、说明。
- 格式中 N 表示数字，A 表示字母，其余为固定前缀或分隔符，括号内为可选部分。
- 示例一般为首都或首府所在地的邮编；标注“格式示例”的仅用于说明格式。
- 来源：万国邮联（UPU）各国邮编规范及各国邮政官方资料，并与 GitHub 开源数据集 [dr5hn/countries-states-cities-database](https://github.com/dr5hn/countries-states-cities-database)、[willfarrell/upu-postcode](https://github.com/willfarrell/upu-postcode) 交叉核对。寄国际邮件时请以收件国邮政官方查询为准。

## 2. 中国大陆省、市、县三级邮政编码表（`中国大陆/` 目录）

| 文件 | 说明 |
|---|---|
| `中国大陆/全国邮政编码表.xlsx` | 工作表：说明 / 省级 / 地级 / 县级 / 港澳台 / 全部，邮编为文本格式，保留前导零 |
| `中国大陆/全国邮政编码表.csv` | 扁平表（UTF-8 带 BOM）。用 Excel 直接打开会丢掉前导零，建议用“数据-从文本导入”并把邮编列设为文本 |
| `中国大陆/全国邮政编码表.md` | 按省、市分组的可读版本 |
| `中国大陆/全国邮政编码表.txt` | 纯文本版本（Windows 换行，记事本可直接打开），按省、市分组，每行一个区县，字段以“ | ”分隔 |

- 34 个省级、333 个地级、2852 个县级行政区（含新疆兵团直辖县级市），以及香港、澳门、台湾。
- 邮编为各行政区政府驻地的通用邮编；已补充 2023 年 6 月以后的区划变更，尚未公布专属邮编或区划代码的以“待公布”标注。
- 基础数据来自国家统计局区划数据（经 [kakuilan/china_area_mysql](https://github.com/kakuilan/china_area_mysql) 整理），剔除开发区等非正式单位并修正 200 余处错误邮编。
