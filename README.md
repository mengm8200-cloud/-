# 全国行政区划邮政编码表

整理日期：2026-11-14

| 文件 | 说明 |
|---|---|
| `全国邮政编码表.xlsx` | 分工作表：说明 / 省级 / 地级 / 县级 / 港澳台 / 全部。邮编与区划代码为文本格式，保留前导零，可直接筛选 |
| `全国邮政编码表.csv` | 扁平表（UTF-8 带 BOM），列：级别、省级行政区、地级行政区、县级行政区、行政区划代码、邮政编码、备注。用 Excel 直接打开会丢掉邮编前导零，建议用“数据-从文本导入”并把邮编列设为文本 |
| `全国邮政编码表.md` | 按省、市分组的可读版本，含港澳台 |

## 覆盖范围

- 34 个省级行政区（省级邮编为省会/首府邮编）
- 333 个地级行政区
- 2852 个县级行政区（大陆，含新疆兵团直辖县级市）
- 香港 18 区（统一 999077）、澳门堂区（统一 999078）、台湾 22 县市（独立 3+3 位邮递区号，给出前三位范围）

## 口径

- 表中邮编为该行政区人民政府驻地的通用邮政编码，寄往该区县可直接使用；同一区县内各乡镇、街道的投递编码可能不同。
- 已补充 2023 年 6 月以后的区划变更：米林市、错那市、白杨市（2023）、和安县、和康县（2024）、重庆两江新区（2025）、岑岭县、草湖市（2026）。尚未公布行政区划代码或专属邮编的，以“—”和“待公布”标注，并暂用所在邮区的通用编码。
- 备注栏标注“待核实”的条目（主要是新疆兵团城市），请以中国邮政官方邮编查询为准。

## 来源与处理

- 基础数据：国家统计局统计用区划代码（2022 年），通过 GitHub 开源数据集 [kakuilan/china_area_mysql](https://github.com/kakuilan/china_area_mysql)（cnarea_2023）获取。
- 校正：剔除了统计用的开发区、新区、管理区等非正式县级单位；对 200 余处明显错误（邮编为 000000、以 99 结尾的占位值、与所在邮区不符的编码）按所辖乡镇街道邮编的多数前缀修正；地级邮编逐一核对。
- 最新区划名单参考 [pluwen/china-cities-dataset](https://github.com/pluwen/china-cities-dataset) 及各地政府公告。
